# Demo video

Put the demo here. The site looks for exactly these files and shows a placeholder until they exist:

- `public/video/demo.mp4`   the video (H.264 MP4, 16:9, ideally under ~15 MB)
- `public/video/poster.jpg` optional still shown before play (16:9)

Commit and push; the Pages workflow publishes them. There is no upload control on the site by design.
